## CARA MEMASANG FOTO — TANPA EDIT KODE

1. Extract ZIP ini.
2. Buka folder `assets`.
3. Masukkan foto kamu dengan nama:
   - foto1.jpg
   - foto2.jpg
   - foto3.jpg
   - foto4.jpg
   - foto5.jpg
   - foto6.jpg
   - foto7.jpg
   - foto8.jpg
   - foto9.jpg
   - foto10.jpg
4. Buka `index.html`. Foto otomatis muncul.
5. Foto yang belum ada akan tampil sebagai area kosong/placeholder browser.

## MUSIK (OPSIONAL)
Masukkan lagu MP3 ke folder `assets` dan beri nama `music.mp3`.
Tidak perlu edit kode.

## UPLOAD VERCEL
Upload seluruh folder project ke Vercel. Tidak perlu build command.
